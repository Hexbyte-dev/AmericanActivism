# Start Somewhere

A phone-friendly, searchable list of 189 civic actions, sorted by how much time you have.

Links were originally curated by [Average Americans' Activism](https://linktr.ee/triple_a_usa), now [The Path Forward](https://pathfwd.netlify.app), and are shared under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). This copy reorganizes them and serves as a backup in case the original goes offline.

The whole site is one file: `index.html`. To add, remove or edit a link, find it in the `LINKS` list near the bottom of that file.
